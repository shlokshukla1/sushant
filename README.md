# 🚀 Sushant | Full-Stack Developer & UI/UX Craftsman Portfolio

A modern, high-performance, responsive personal portfolio website showcasing full-stack engineering expertise, interactive case studies, dynamic skill matrices, and a digital resume.

![Portfolio Preview](assets/avatar.jpg)

## ✨ Highlights & Features

- **Cyber Obsidian Glassmorphism**: Tailored dark theme using fluid glass surfaces, subtle neon highlights, and backdrop blurs.
- **Interactive Ambient Canvas**: Constellation particle network responding to mouse position and screen resize.
- **Dynamic Role Typewriter**: Interactive headline animator reflecting multi-disciplinary engineering competencies.
- **Categorized Skills Matrix**: Filterable skills catalog with animated proficiency indicators (Frontend, Backend, DevOps, Soft Skills).
- **Interactive Project Showcase**: Filterable portfolio with in-depth Case Study modal dialogs, tech stack pills, and live demo links.
- **Integrated Digital CV & Resume Preview**: Modal preview with one-click print-to-PDF functionality.
- **Interactive Contact Form**: Client-side validation with responsive toast feedback notifications.
- **Zero Bloat**: Built purely with semantic HTML5, modern vanilla CSS3, and vanilla ES6+ JavaScript. No bulky frameworks required for fast load times.

## 🛠️ Built With

- **HTML5**: Semantic tags, accessible landmarks, OpenGraph SEO metadata.
- **CSS3**: Custom properties (CSS variables), CSS Grid, Flexbox, glassmorphism, keyframe animations.
- **JavaScript (ES6+)**: Canvas API, Intersection Observer API, dynamic DOM manipulation, clipboard API.
- **Fonts & Icons**: Outfit, Space Grotesk, JetBrains Mono, FontAwesome 6.5.

## 🌐 Deploy to Vercel

### Option 1: Via GitHub (Recommended)
1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "Deploy: Complete full-stack portfolio"
   git push origin main
   ```
2. Open [vercel.com](https://vercel.com) and log in with GitHub.
3. Click **"Add New Project"** -> Select **`sushant`**.
4. Leave framework preset as **"Other"** (Root Directory `./`).
5. Click **"Deploy"** — your live site will be active in seconds!

### Option 2: Via Vercel CLI
```bash
npx vercel
```
